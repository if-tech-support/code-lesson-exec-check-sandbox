# Review Guideline

## 1. 目的
品質向上と知識共有を両立し、レビューコストを最適化する。

## 2. レビュアーが確認するチェックリスト
- [ ] PRの目的と実際の差分が一致している
- [ ] 秘密情報や不要な生成物が含まれていない
- [ ] 自動テストを設定している場合、結果が成功している
- [ ] 変更の確認方法と結果が書かれている
- [ ] PR テンプレートの全項目が埋まっている

## 3. レビュアーの行動指針
1. **3 点以上** 指摘がある場合は一度まとめてコメント  
2. コメントは *提案* / *必須* を明確に記載  
3. 2 営業日以内にレスポンス
